# **App Name**: AdmitEase

## Core Features:

- Dashboard: Display key performance indicators (KPIs) via cards, including Total Assigned, Active Cases, Interviews, and Pending Actions. Also features a table of assigned students with search and filter functionality for Status, School, Grade, and Date.
- Application Management: Enable admins to Create, Read, Update, and Delete applications. All columns will support search and filtering: ID, Student Name, School, Grade, Status, Application Date, Phones, Assigned Employee, and Actions (Update/Delete).
- Interview and Assessment: Tabbed interface (Scheduled, Pending, Results) for managing interviews and assessments with search and filter capabilities.
- Oral Interview Management: Tabbed interface (Upcoming, Results, Retests) for managing oral interviews, including search and filter functionalities.
- Approval Workflow: Sections for Pending, Approved, and Rejected applications with search functionality and approve/reject actions.

## Style Guidelines:

- Primary color: Deep sky blue (#3498DB), conveying trust and professionalism.
- Background color: Light gray (#ECF0F1), for a clean and unobtrusive backdrop.
- Accent color: Emerald green (#2ECC71), highlighting approvals and positive actions.
- Body and headline font: 'Inter', a grotesque-style sans-serif for a modern and neutral look. 
- Consistent use of simple, outline-style icons from a library like FontAwesome to represent actions and categories.
- Use a clean, tabular layout with clear separation of data through defined columns and rows. Consistent spacing for readability.
- Subtle transitions and animations to provide feedback on actions like approving or rejecting applications.
